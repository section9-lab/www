title: How do I install vibe hud?
---
You need macOS 15.6 or later. Get the latest DMG from the [download page](/download/), move VibeHUD.app into Applications, and launch it. Open Agent Hooks in the notch menu, enable the integration you use, and start a new agent session so it loads the hooks. See the [setup guide](/docs/) for the full workflow.
