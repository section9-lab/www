title: Which agents does vibe hud support?
---
The app includes integrations for Claude Code, Codex, Cursor, GitHub Copilot, Pi, OpenCode, WorkBuddy, and Qwen Work. Manage each integration from Agent Hooks in the notch menu. Available actions depend on the agent and terminal setup. The [compatibility guide](/docs/compatibility/) explains the integration types and limitations.
